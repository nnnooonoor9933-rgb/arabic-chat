# الدردشة العربية — ArabiChat

هذه نسخة GitHub جاهزة من بيئة مشروع الدردشة العربية.

## تشغيل الموقع
- افتح `index.html` مباشرة عبر GitHub Pages.
- إعداد Firebase موجود في `firebase-config.js`.
- المشروع يستخدم Firebase Realtime Database للمشروع `arab-chat-8148c`.

## ملاحظة
هذه الحزمة تحتوي على واجهة التشغيل الحالية، إعدادات Firebase، هيكل Android، وملفات التحليل والاستخراج.
الخادم القديم وملفات PHP وقاعدة بياناته الأصلية ليست داخل APK، لذلك لا يمكن اعتبار هذه الحزمة نسخة كاملة من الخادم القديم.

## Android
مشروع Android موجود داخل مجلد `android/`.

## Firebase
ملفات Firebase موجودة داخل `firebase/`.
قواعد قاعدة البيانات الحالية مقفلة كما كانت في بيئة الإعداد، ولا يتم فتحها تلقائياً.
